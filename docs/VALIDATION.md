## 真实网络冒烟测试

使用 `dnsping-check` 运行与 GUI 相同的网络引擎；没有替换或伪造解析结果。

域名：`remoteassistance.support.services.microsoft.com`；IPv4，TCP 80，各 3 次。本轮示例：

| DNS | 首个返回 IP | DNS 耗时 | 平均 TCP 延迟 | 成功 |
| --- | --- | --- | --- | --- |
| 202.103.224.68 | 23.42.160.121 | 8.17 ms | 244.62 ms | 3/3 |
| 223.5.5.5 | 23.47.107.171 | 200.64 ms | 328.90 ms | 3/3 |
| 119.29.29.29 | 23.6.177.116 | 611.46 ms | 179.70 ms | 3/3 |
| 114.114.114.114 | 23.5.0.219 | 376.31 ms | 197.43 ms | 3/3 |

正确推荐 `23.6.177.116`。仅记录该轮观测；之后的 CDN 地址、解析耗时和延迟会随网络和时间变化。

域名：`www.example.com`；IPv4，ICMP，各 2 次：阿里返回 `104.20.23.154`，平均 212.50 ms；腾讯返回 `172.66.147.243`，平均 193.00 ms。两者均成功 2/2，推荐后者。IPv6 ICMP 在本机 `::1` 通过；不把回环测试当作公网 IPv6 可达性验证。

## 服务商编辑与主题更新

- 编辑内置服务商不改变其内置标记及勾选状态；编辑自定义服务商支持 IPv4 / IPv6 切换，不增加条目数量。
- 仅修改名称、保留自己的原 IP 是合法操作；改成其他服务商已使用的 IP 会被拒绝。
- 无效名称、无效 / 未指定 IP、重复 IP 和无效条目索引均不会修改现有配置；32 条上限只限制新增，不限制编辑。
- 旧版配置不含主题字段时默认使用深色，并保留既有域名和服务商修改。
- 以上行为通过新增的 4 项自动化测试；主题视觉及新版编辑表单的手动操作待用户验收，未继续接管鼠标。

- 首次启动在程序目录创建 settings.json。
- 旧 AppData 配置迁移后保留原文件；已存在的程序目录配置优先，不被旧配置覆盖。
